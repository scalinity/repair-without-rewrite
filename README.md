# LocalFlowResearch

Authorized bounded foundation for the from-scratch Transformer research program. No publication gates are claimed passed. No final training, protocol freeze, remote or production integration is authorized.

Immutable specification and provenance: `docs/design-inputs/`. Accepted review and prospective amendments: `docs/reviews/`. On-disk test and qualification evidence: `docs/reports/`.

Run development tests with `.venv/bin/python -m pytest`. Dependency identity is pinned in `uv.lock`; no build step is needed.
