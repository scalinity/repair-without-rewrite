Independent input audit found mono 16 kHz PCM16 FLAC for every clip; ffmpeg decoded PCM is byte-identical to soundfile. Waveforms are finite, nonempty, correctly bounded, with no resampling or cropping needed. Full audio/input/model hashes and six-case measurements are in the reproducible [CPU reference audit](../../benchmarks/parakeet_reference_audit.py) and its ignored `parakeet-reference-cpu-attempt01/reference_receipt.json` receipt. Six cases comprise both failures, two normal affected clips and two normal unaffected clips.

The original STFT computes frame count using window width 400 but reads FFT width 512. Seven original clips have an extra frame extending 80 elements past the logical padded allocation. The repeated outputs match unchecked NaN argmax choosing token/duration zero, followed by ten-symbol forced frame advances: 61×10 and 42×10. A controlled, fully allocated 80-NaN tail independently poisons one window/FFT frame and then every normalized feature, demonstrating that multiplying an invalid NaN tail by a zero-padded window does not protect the computation.

**The original invalid-tail bytes were not captured.** Early materialization of waveform/FFT intermediates in `parakeet-localize-attempt01` eliminated the pathology: all inspected tensors were finite. Instrumentation changes allocation/execution; that run cannot locate an unperturbed first NaN creation point. The evidence diagnoses a concrete memory-bounds defect and demonstrates its poisoning mechanism; attribution of the exact historical nonfinite values to that tail remains strongly supported but not directly observed. No broader causality or model defect is claimed.

`parakeet-frame-repair-attempt01` ran the SAME twelve clips twice: 24/24 finite calls, zero pure-unknown outputs, byte-identical transcripts across both passes. The two previously pathological clips now produce ordinary transcripts with remaining reference-relative recognition errors; they remain in the cohort. Subsequent source construction is admitted only for single unchunked mono 16 kHz PCM16 clips of 2–12 seconds, with the same model/weights/vocabulary and explicit byte-frozen hypotheses shared by every restoration system. Shorter/longer, streaming, padded mixed-length batches and other precision/model versions are outside this qualification.

Full original-model inference was not performed: there is no measured transcript/whole-model equivalence claim.
